# Trading Journal Analysis

## Overview
This project analyzes my personal trading journal using SQL
to evaluate trading performance, strategy effectiveness,
and trading behavior.

## Objectives
- Evaluate overall trading performance
- Analyze profitability across different months
- Compare performance across trading sessions and weekdays
- Evaluate trading setups, timeframes, and confluences
- Identify behavioral patterns and risk management issues

## Tools
- MySQL
- SQL
- Tableau (Coming Soon)

## Dataset
Personal trading journal containing trade history,
performance metrics, trading setups, sessions,
risk/reward ratios, and trade outcomes.

## Key Questions
- Is the trading strategy profitable?
- Which trading sessions perform best?
- Which setups have the strongest performance?
- Does trade duration affect profitability?
- Are there behavioral patterns during losing trades?
